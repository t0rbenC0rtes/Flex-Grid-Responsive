# Responsive Design

## Overview
Responsive Design is a project focused on creating a dynamic landing page that adapts seamlessly to various screen sizes. This design is based on a Figma mockup but places additional emphasis on responsive web design principles.

## Tech Stack
- **HTML**
- **CSS**
- **Sass**
- **Media Queries**

## Project Goal
The main objectives of this project are to:
1. Replicate a Figma design as a responsive and fully functional landing page.
2. Utilize Sass for efficient and modular styling.
3. Apply media queries to ensure the design is adaptable to different screen sizes and devices.

## Features
- Accurate recreation of the Figma design with a responsive layout.
- Mobile-first design approach, ensuring optimal usability on smaller devices.
- Use of Sass for better CSS management and scalability.
- Smooth CSS animations for an enhanced user experience.

## Notes
This project is a perfect starting point for:
- Understanding the principles of responsive web design.
- Learning how to leverage Sass to organize and optimize your CSS.
- Practicing media queries to create designs that work on any device.
